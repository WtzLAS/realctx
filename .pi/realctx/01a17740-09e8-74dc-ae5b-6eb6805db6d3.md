Global memory paths are stored as `~`, `~/…` (under user dir) or absolute paths outside it (`src/paths.ts` header, `normalizePathScopes(…, "global")` in `src/files.ts`). Any code that resolves them must go through `toAbsoluteScope(p, "global", …)`; stripping `~/` and joining onto `homeRoot()` wrongly re-roots absolute paths under `~` (was a bug in `engine.checkPaths`, so existing absolute global paths showed up as missing and `prunePaths` deleted them). `scopeExists(root, scope, repo)` now accepts absolute scopes. Regression test: tests/pathnotes.test.ts "global absolute paths outside the user directory…".
