The `judge.shadow` setting was removed: judge drop/summarize verdicts always queue and apply (event kind `verdict`; old `shadow` events are still shown by `/realctx recent` as "logged only"). Stale `judge.shadow` keys in settings files vanish because `mergeInto` in `src/config.ts` keeps only keys present in DEFAULT_SETTINGS. In `tests/context.test.ts` the mock judge's `stillNeeded` defaults to 0.9 (keep) so rule/image tests aren't disturbed by judge drops; tests that want judge drops set `stillNeeded = 0.02` and must reset it to 0.9 at the end.
