`extensions/realctx/index.ts` `refreshStatus` builds `🧠 <n>[ (+P queued)] · 📉 −<reclaimed>|0[ (+Q queued)][ · 📊 <pct>%] <spinner>[ · setup: /realctx settings]` (`compactTokens`: `130.4k`). `📊` = `layer.status().usage.tokens` (realctx's own estimate after drops/history, `lastUsage`) divided by the model's FULL `ctx.model.contextWindow` (comparable to Pi's footer; thresholds use the safe window instead). Omitted when the layer is inactive or before the first request; it exists because Pi's footer re-estimates the raw transcript after retry `context_edit`s. The `context` handler also calls `refreshStatus` to update the percentage every request. Text is cached in `statusBase`; a spinner (Pi's loader frames ⠋⠙⠹…, 80 ms, `ctx.ui.theme.fg("accent")`, timer unref'd) runs while `busy()` = memory `draining` || `ContextLayer.busy()` (judge pass, user-fact capture in flight, historian `preparing`). Ticks only re-render; when work ends the tick calls `refreshStatus` once and stops. Anything new that runs model requests in the background should feed `busy()` and call `refreshStatus`/`syncSpinner` when it starts.
