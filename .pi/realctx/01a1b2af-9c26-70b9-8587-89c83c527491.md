`context.disabledModels: string[]` (src/config.ts, default `[]`; entries `provider/model` or `model`, case-insensitive, `*` wildcard, matched by `matchModel()` in src/config.ts). `ContextLayer` tracks the session model via `setModel()` (called in `reset`, at the top of `transform` from `ctx.model`, and by the `model_select` handler in extensions/realctx/index.ts, which notifies paused/resumed). `get active()` = `disabledReason === undefined && modelOff === undefined`; `modelOff` is evaluated live against settings, so `disabledReason` stays reserved for session-level reasons. While paused everything gated on `layer.active` stops (transform passes messages through, no capture/judge/history, Pi threshold compaction not cancelled); applied drops stay in memory and render again after switching back. `LayerStatus.modelOff` (only set when no other disabledReason) makes `refreshStatus` show ` · 🛑` instead of the `📉` part. Settings page field `context.disabledModels` (comma-separated text). Tests: "context.disabledModels pauses…" in tests/context.test.ts, "matchModel: …" in tests/policy.test.ts.
