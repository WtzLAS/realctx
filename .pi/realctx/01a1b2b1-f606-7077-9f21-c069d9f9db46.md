`extensions/realctx/settings-page.ts` has a `model-list` FieldDef kind (`list(s)` returns the entries, `set(s, text)` takes comma-separated text or "(none)"). Its submenu `modelListPicker` is a `FilterPicker` over `ctx.modelRegistry.getAvailable()`: first row `✎ edit as text…` (InputSubmenu, for `*` patterns), then the listed entries as `✓ entry`, then the unlisted models. Enter toggles a model and the picker stays open (`FilterPicker.setItems(items, selected)` keeps the filter text and the highlighted value); Esc closes with `d.get(draft)`. The SettingsList onChange ignores this kind because the picker updates `draft`/`dirty` itself. `FilterPicker` also takes an optional `hint` (footer line). Test: "settings page: disabled models are toggled…" in tests/tui.test.ts (fakeCtx; override `ctx.modelRegistry.getAvailable`).
