- `src/config.ts`: v3 defaults `context.applyMaxTokens = 0` and `history.prepareMaxTokens = 0` (both caps disabled), `context.applyThreshold = .4` and `history.prepareThreshold = .3`. Optional token caps still cap threshold-derived token counts when explicitly set. Editable in `/realctx settings` (`extensions/realctx/settings-page.ts`).
- `createCompleter` (`src/rewrite.ts`) enforces `timeoutMs` using `Promise.race` + `AbortController`: `DEFAULT_COMPLETION_TIMEOUT_MS = 30_000`, `HISTORIAN_TIMEOUT_MS = 60_000`. After `MODEL_COOLDOWN_STRIKES = 2` consecutive per-model failures, background calls fail fast for `MODEL_COOLDOWN_MS = 2 * 60_000`; `resetModelCooldowns()` clears cooldowns. This covers `ContextLayer` summarize/captureFacts/userExtract and `HistoryManager.prepareInBackground`. Foreground calls still attempt the provider and clear cooldown on success.
- `HistoryManager.summarize` (`extensions/realctx/history-layer.ts`): if an existing `h.completer` fails or returns empty during `background === true` preparation and `history.emergencyFallback` is true, records `lastError` and emits deterministic `fallbackHistory` (`model: "fallback"`). Explicit `/realctx compress` (`prepareNow`, `background === false`) surfaces the error without fallback.
- `ContextLayer.judgePass` (`extensions/realctx/context-layer.ts`) still sequentially awaits `this.summarize(ctx, meta)` for each `"summarize"` verdict before caching/queuing it; completer waits are bounded by timeout/cooldown rather than unbounded.
